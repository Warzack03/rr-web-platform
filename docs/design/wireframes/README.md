# Wireframes Stitch

Estos wireframes son referencia visual y funcional para la reconstrucción del frontend.

No copiar HTML estático ni datos literales.
Usarlos como guía de:
- estructura de pantalla
- distribución de bloques
- jerarquía visual
- navegación
- densidad de información
- separación entre home, páginas públicas y backoffice

## Público

- `home_rising_raimon.png`: referencia principal para la home pública.
- `detalle_primer_equipo_rising_raimon.png`: referencia para `/primer-equipo`.
- `listado_de_equipos_rising_raimon.png`: referencia para `/equipos`.
- `detalle_equipo_cantera_simplificado_rising_raimon.png`: referencia para `/equipos/[teamSlug]`.
