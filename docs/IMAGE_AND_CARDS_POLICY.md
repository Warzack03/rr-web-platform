# IMAGE_AND_CARDS_POLICY.md

## Storage decision

Images are stored as files or external URLs, not inside MySQL as binary/BLOB data.

The database stores metadata only:

- URL.
- Storage path.
- Alt text.
- MIME type.
- Width.
- Height.
- Size bytes.
- Type/category.
- Created by.

## Storage options

MVP primary option:

- Hostinger filesystem upload directory, e.g. `/uploads`.
- Store relative/public URLs in MySQL.

Future options:

- Cloudinary.
- S3-compatible storage.
- Cloudflare R2.
- External image URLs for opponent logos.

## Image types

- Team logo.
- Team banner.
- Opponent logo optional.
- Player photo.
- First Team premium card image.
- Generated standard card assets.
- News cover image.
- Hero/banner images.

## Upload permissions

Only `superadmin` and `manager` can upload images.

Coaches cannot upload:

- Player photos.
- Team logos.
- Team banners.
- Cards/cromos.
- News media.

## Opponent logos

Opponent logo is optional. If present, store it as uploaded media or external URL metadata. If absent, use a placeholder.

## Cards/cromos

### First Team

- Uploaded premium card images.
- Managed by superadmin/manager.
- Associated to player + team + season.

### Other teams

- Generated by the web.
- No uploaded final card image required.
- Uses player/team/stat data.

Generated card fields:

- Foot.
- Public name.
- Shirt number.
- Country flag.
- Position.
- Goals.
- Assists.

## Videos

Videos are external URLs only. Do not upload video files to Hostinger in MVP.

Supported contexts:

- News external video links.
- Played First Team match video URL.

## Optimization

- Prefer WebP/AVIF where possible.
- Avoid huge unoptimized uploads.
- Keep alt text.
- Generate thumbnails when useful.
- Avoid heavy server-side image processing in Hostinger if it risks performance.
